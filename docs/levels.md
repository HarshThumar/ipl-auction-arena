# Levels: IPL Auction Arena goals, from L0 to L9

*Set 11 Nov 2026. Each level is harder than the one before it, and each has a "done when" test you can check. **No level may be skipped**, because each one is the gate for the next. Work on a level may start early and overlap with the previous one, but **a level's gate cannot pass until the previous level's gate has passed.** The register rows each level must close are in brackets ([failure-register.md](failure-register.md)). The **depth** of L1/L3/L4 (how deep the agents and the auction go) is locked in [architecture.md](architecture.md) — read it with this file.*

**Year labels:** "2024 season" means the IPL season; its auction happened the previous December (Dec 2023). Always write both.

**Cut line if time runs short before 16 Dec:** L0–L4 and L7 are mandatory. L5 and L6 shrink to "report what we have, with CIs". L8–L9 are after the auction by design.

**"10/10" means:** L7 + L6 + L5 done honestly (a timestamped forecast nobody else made, scored in public against pundits and the best existing model, answering a real question) **and** the realism pass in architecture.md (live open bidding, huddles, opponent model from live bids, the v0→v6 ladder scorecard).

## Depth lock (12 Nov 2026) — the showcase is agent craft; see [architecture.md](architecture.md)
The purpose beyond the forecast is to **showcase how deep a well-engineered agent can be, inside an auction that feels real.** These deepen the existing levels (they do not add new numbered ones):

| Level | Baseline "done when" (above) | Depth locked on top (architecture.md) |
|---|---|---|
| **L1** | engine replays real auctions, zero violations | **Living auction:** **live open bidding**, real player **sets**, **accelerated round**, **RTM** where the season had it, live board; an **auctioneer agent** that calls the room (Part B, B1–B2) |
| **L3** | one bidder, 0 invalid actions on the fuzz suite | **Deep bidder, built v0→v6:** v0–v3 CORE (tools, live decisions, plan with ceilings + backups); v4–v6 STRETCH (memory + reflection, **war room that argues at huddles**, **opponent model from live bids + price-pushing**). Guardrails green throughout (Part A) |
| **L4** | 10 agents pass KS validity tests, ≥20 seeds | **Real bidding wars** with a full bid log; huddles under time/partial-info budget; bidding-war realism check vs live blogs; Monte-Carlo distribution (Part B, B3–B5) |

**Realism rule (12 Nov):** if a real IPL auction room doesn't have it, we don't build it. Removed: jump-bidding, skill library, in-auction trade negotiation, agent-to-agent messages (see architecture.md, "Removed in the realism pass").

**Floor we never drop:** live engine + guardrailed bidder v3 + auctioneer + ≥20 seeds. **The forecast freezes on the highest bidder version that is green on 13 Dec.** **Encore (L8/paper):** deep recursive theory-of-mind and the full broadcast UI.
